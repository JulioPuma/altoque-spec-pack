¿Solicitar otra consulta de la misma operación?

Altoque consultará al core simulado la operación original. No se crea otra operación, no se cambia el identificador y no se modifica el payload.

Identificador de la operación (no editable)
Motivo que quedará registrado

Si el resultado vuelve a ser inconcluso (RECIBIDA, PROCESANDO, NO_ENCONTRADA o sin respuesta), el caso sigue en revisión con el resultado pendiente.

Comportamiento a validar

  • Abrir el caso solo lee evidencia registrada; no consulta al core. Solo «Solicitar otra consulta» lo hace, y siempre sobre el mismo operacionId y los mismos datos.
  • El diálogo muestra el identificador como texto de solo lectura: no hay campo para cambiarlo ni para editar el payload.
  • RECIBIDA, PROCESANDO, NO_ENCONTRADA o timeout dejan el caso en revisión con resultado pendiente. NO_ENCONTRADA no es un fallo.
  • EXITOSA, RECHAZADA o FALLIDA_DEFINITIVA, una vez persistidas, cierran el caso: pasa a solo lectura y desaparecen los comandos.
  • Cada comando envía motivo, correlación, versión esperada y clave de idempotencia. Ante 409 se muestra «Recargar» y nunca se reenvía solo; tu motivo se conserva.
  • Un error de red permite reintentar con la misma clave de idempotencia, para no duplicar la consulta.
  • El auditor ve el caso completo sin formularios ni botones de comando. Un caso inexistente o ajeno muestra el mismo 403 que la falta de permiso.
  • Supuesto: registrar una observación incrementa la versión del caso pero no cambia el estado del desembolso.

Reglas aplicadas

  • RN-023 / RN-024 / RN-133 Recuperar consulta la operación original; nunca otro identificador ni otra operación lógica.
  • RN-135 Mismo identificador y mismos datos devuelven la operación original sin ejecutar otra.
  • RN-052 / RN-148 NO_ENCONTRADA es inconclusa: se mantiene pendiente.
  • RN-144 / RN-149 RECIBIDA, PROCESANDO, timeout o respuesta inválida son inconclusos.
  • RN-145–147 / RN-234 Resultado terminal solo con EXITOSA, RECHAZADA o FALLIDA_DEFINITIVA persistidos.
  • RN-072 Sin evidencia concluyente, el resultado sigue pendiente.
  • RN-151–153 / RN-236 Respuestas tardías solo con versión vigente; un terminal no se modifica.
  • RN-232 / RN-233 / RN-238 Facultades del operador de revisión de desembolso.
  • RN-235 Auditoría de identidad, instante, motivo, evidencia, correlación, versión y resultado.
  • RN-239 Auditor sin transiciones. RN-243 403 sin revelar existencia.
